## 2. so sánh chuỗi

| toán tử | ý nghĩa |
| ------- | ------- |
| `=`     | `=`     |
| `!=`    | `!=`    |
| `<`     | `<`     |
| `>`     | `>`     |
- không có gì khác ở 2 toán tử đầu
- 2 toán tử cối so sánh dựa trên bảng ascii 
## 3. toán tử số học
- là các phép toán thường, như các ngôn ngữ lập trình khác

- vẫn là `+`, `-`, `*`, `/`, `%`
- thực hiện lũy thừa dùng các công cụ ngoài như `bc` , `awk`
## 4. toán tử logic

- giống vs ngôn ngữ lập trình khác: `&&` - logic and, `||` - logic or , `!` - logic phủ định
## 5. kiểm thử tập tin

- `-e` - kiểm tra tệp có tồn tại ko
- `-d` - folder có tồn tại ko
- `-f` - 1 file là file thường ko
- `-s` - tệp có trống hay ko
